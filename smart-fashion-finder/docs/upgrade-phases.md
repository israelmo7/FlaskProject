# StyleNear — שלבי שדרוג (Avatar · Catalog · UI · AI)

מסמך משימות פעיל אחרי Standard Fit / Fitted Looks. כל שלב נמדד מול ההגדרה כאן לפני פיתוח.

## Phase A — לוק מלא על הדמות

| # | משימה | הגדרה |
|---|--------|--------|
| **A1** | לוק מלא (עליון+תחתון+עליונית) | כשלובשים כמה שכבות בגד — כולן נשארות גלויות יחד (קומבו Fitted כשקיים לכל השכבות, אחרת בסיס + overlays). לא מסתירים פריט בגלל "דומיננטי יחיד". |
| **A1b** | Anchor Points (Head→Toe) | רשת עוגנים אחידה על Standard Fit 480×900 ב־`overlayAnchors.ts` + `GameFashionAvatar`: `head` (כובע), `shoulders` (top/outer/dress), `hips` (bottoms — כיסוי בוקסר), `feet` (הנעלה). zIndex: bottom < top < outer < shoes < hat. |
| **A1c** | Outerwear Alignment | חוקים גלובליים ב־`outerwearAlignment.ts` לכל עליונית ולכל persona: Neckline Safety, כיסוי שרוולים (scaleX), Open-Front cutout כשיש Top מתחת (`*-open.png`). |
| **A2** | בסיס נקי / יחף | גבר/אישה יחפים; אישה בהלבשה תחתונה; גבר — בוקסר בלבד (ללא גופייה). הלבשת בגדים דרך Fitted Look / overlays על רשת 480×900. |
| **A3** | הסרת UI גובה/משקל מההלבשה | Standard Fit קבוע — בלי שליטה ויזואלית בגובה/משקל על הבגד. |

## Phase B — נכסים וקטלוג

| # | משימה | הגדרה |
|---|--------|--------|
| **B1** | נכסי אישה מלאים | Fitted Looks / overlays ייעודיים לאישה (לא placeholder בלבד). |
| **B2** | כיסוי קטלוג | לכל מזהה קטלוג — Fitted Look או alias + fallback בטוח. |
| **B3** | מנגנון לוגואים ומותגים | לכל פריט בקטלוג — שדה מותג + לוגו (למשל Zara, Adidas). מלבני המותג במסך הבית מסננים **בדיוק** את הפריטים של אותו מותג (לחיצה/סינון לפי `brandId`, לא התאמת טקסט חלקית). תצוגת לוגו/שם מותג עקבית בכרטיס, פרטים וחיפוש. |

## Phase C — ניווט ו־UX

| # | משימה | הגדרה |
|---|--------|--------|
| **C1** | ניווט | זרימה ברורה בית → פריט → הלבשה / חנות בלי מסכים מיותרים. |
| **C2** | UI | יישור מסכים לעברית RTL ולשפת המוצר אחרי Standard Fit. |

## Phase D — AI Assistant (עוזר קניות / חיפוש בלבד)

| # | משימה | הגדרה |
|---|--------|--------|
| **D1** | Shopping / Search Assistant | ה־AI **אינו** מלביש את הדמות ו**אינו** ממליץ על שילובי לוק. התפקיד היחיד: לעזור למשתמש **למצוא מוצרים בקטלוג** בשפה חופשית (למשל «חולצה לבנה מכופתרת», «מעיל חורף שחור», «שמלה לאירוע»), לסנן ולהציג את הפריטים המתאימים ביותר בצורה נוחה ומהירה. |

### Out of scope ל־Phase D

- הלבשת אווטאר / try-on דרך הצ׳אט  
- המלצות סטיילינג או «מה הולך עם מה»  
- בניית outfit אוטומטית על הדמות  

הלבשה נשארת במסך האווטאר / כרטיס המוצר — לא באחריות עוזר ה־AI.
