# StyleNear — פערים מול ה־MVP וסדר עבודה

מסמך קישור בין [`mvp.md`](./mvp.md) ל־[`ux-flow.md`](./ux-flow.md) לבין הקוד הקיים.

## סיכום מהיר

| | סטטוס |
|---|--------|
| מסכים בסיסיים (בית, ניתוח, חנויות, פרופיל, אזור, עגלה) | קיימים |
| עיצוב עברית / RTL | קיים |
| ליבת הערך: זיהוי אמיתי + מלאי חי + WhatsApp | **חסר / דמו** |

## פירוט פערים

### חובה ל־MVP אמיתי

1. **Vision API** — להחליף את ה־mock ב־`src/hooks/useGarmentRecognition.ts`
2. **מלאי פריט×חנות×מידה** — מעבר מ־`inventory.json` סטטי למקור שמתעדכן (גם גיליון/אדמין פשוט לפיילוט)
3. **WhatsApp לחנות** — CTA ב־`StoreCard` עם הודעה מוכנה (“יש מידה X לפריט Y?”)
4. **שעות פתיחה** — שדה בחנות + תצוגת “פתוח עכשיו”

### כבר מכוסה מספיק ל־MVP UI

- כותרת בית בלי ניווט באנגלית
- SALE לא על המסלול הראשי (נשאר כתווית משנית בלבד)
- עגלה ואזור נפתחים למסכים אמיתיים
- שמירת מידה + פרופיל בובה ב־AsyncStorage
- ניווט Google Maps מחנות

### לא לגעת עד שהליבה עובדת

- שיפורי פוטוריאליזם לבובה
- התראות מלאי
- פאנל חנות מלא
- תשלומים

## הצעד הבא המומלץ לפיתוח

**WhatsApp לחנות + הדגשת מידה בכרטיס חנות** — הכי מהיר לחיזוק סגירת הביקור, בלי תלות ב־API חיצוני של Vision.
