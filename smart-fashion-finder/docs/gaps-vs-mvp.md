# StyleNear — פערים מול ה־MVP וסדר עבודה

מסמך קישור בין [`mvp.md`](./mvp.md) ל־[`ux-flow.md`](./ux-flow.md) לבין הקוד הקיים.

## סיכום מהיר (עודכן)

| | סטטוס |
|---|--------|
| מסכים בסיסיים (בית, תיוג, ניתוח, חנויות, פרופיל, אזור, עגלה) | קיימים |
| עיצוב עברית / RTL | קיים |
| תיוג ידני אחרי צילום | **קיים** (`/tag`) |
| מלאי פריט×חנות×מידה (`sizeStock`) | **קיים** (JSON ידני) |
| WhatsApp / טלפון / שמרו לי | **קיים** ב־`StoreCard` |
| שעות פתיחה + פתוח עכשיו | **קיים** |
| חיפוש: סביבי/אחר/על הדרך + מיקרופון | **קיים** בכותרת |
| קטגוריות ליד SALE | **קיים** |
| Vision API אמיתי | עדיין חסר (מוכן להחלפה) |
| מלאי חי מחנויות | עדיין ידני לפיילוט |

## הצעד הבא המומלץ

חיבור Vision API אמיתי במקום תיוג ידני, או סנכרון מלאי מחנויות הפיילוט.
