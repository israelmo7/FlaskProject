## 8 סעיפי הפיתוח המומלץ — בוצעו

1. תיוג ידני חכם  
2. מודל מלאי פריט→חנות→מידה  
3+5. שמרו לי / WhatsApp + טלפון  
4. שעות פתיחה + פתוח עכשיו  
6+7. תפריט מיקום + מיקרופון בחיפוש  
8. שורת קטגוריות ליד SALE  

## הצעד הבא המומלץ

חיבור Vision API אמיתי במקום תיוג ידני, או סנכרון מלאי מחנויות הפיילוט.
